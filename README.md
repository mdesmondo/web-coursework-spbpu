# AgentLab - учебный сайт по верстке (СПбПУ)

Учебный проект по дисциплине "Верстка и прототипирование сайтов". Тема сайта - устройство ИИ-агентов (LLM, инструменты, память, планирование и тестирование). Также на сайте собраны все лабораторные задания за семестр и описание самого проекта.

Ссылка на GitHub Pages: https://mdesmondo.github.io/web-coursework-spbpu/

## Что внутри проекта

- `index.html` - главная страница (выполнена как лэндинг с обзором темы, схемами, карточками заданий и формой обратной связи)
- `pages/agents.html` - подробная статья о том, как устроены современные ИИ-агенты
- `pages/task1.html` - Задание 1: CSS-рисунок (динозавр на чистом CSS, вариант 1)
- `pages/task2.html` - Задание 2: Flexbox-ролик (сценка с принцем и лягушкой без JS, вариант 3)
- `pages/task3.html` - Задание 3: DOM-тест "Ругательства" (вариант 2)
- `pages/coursework.html` - описание макета, структуры сайта, CSS-логотипа и задела под серверную часть
- `tasks.html` - обзорная страница со всеми лабораторными заданиями

## Особенности верстки

1. **Табличная верстка не используется** - вся раскладка сделана на Flexbox и CSS Grid, а обтекание иллюстраций внутри текста реализовано через `float: left` и `float: right`.
2. **Обязательные блоки на каждой странице** - везде есть шапка (`header`), меню (`nav`), основной контент (`main`), боковая колонка (`aside`, где нужно оглавление) и подвал (`footer`).
3. **Логотип на чистом CSS** - иконка робота-агента в шапке и подвале собрана без картинок и SVG, только через `div`/`span`, рамки, `border-radius` и псевдоэлементы `::before` и `::after`. Базовый размер в шапке 48x48 пикселей (в подвале 36px, на странице описания также показана версия 72px).
4. **Задел под серверное программирование** - шапка и подвал одинаковы по структуре, поэтому их легко вынести в базовый шаблон Jinja2 (`base.html`), а форма на главной странице настроена на отправку `POST`-запроса на `/api/feedback`.

## Как запустить локально

Достаточно открыть `index.html` в браузере или запустить встроенный сервер Python из папки проекта:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.
